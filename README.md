# Retake-project
Library Application Code 
The purpose for this retake proyect is to create a code for a library that manages books, users, and borrowing records. So basicly my code is going to show a user, the book the user wants to borrow, the 
book's isbn (is the identification number of the book,  show if the book is available or not and show if 
the user has any other book already borrowed 
The example to use the code is on the module "main". 
The files/modules names are the next: Main, Manager and Entities. 
Some of the key features for each class are for example: isbn (the identification number of a book), title, user_id, name, is_active, etc.
